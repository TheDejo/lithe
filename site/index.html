A test runner for AI agents.

Write down what your agent should and shouldn't do. Run it on every commit. When its behaviour changes, Lithe shows you the step where it happened.

What you get

The test runner you know, with what agents need.

01

Tests

describe, test and expect. TypeScript runs as is, with no config.

02

Mocks

Stub the Anthropic or OpenAI client your agent already uses, and check every tool call.

03

Assertions

Check meaning, not wording: parts of a string, a shape of JSON, one of several answers.

04

Retries

Give real model calls more time and another try, and still see which tests needed it.

05

Traces

Every model call, tool call and note is recorded, and printed under a failing test.

06

Compare

Diff two runs and find the first step where an agent did something different.

How it looks

Script the model. Test the agent.

Stub the client, decide what the model says, and assert on what your agent does with it. No network, no API key.

support.test.tsconst create = spyOn(client.messages, "create");

test("looks up the order first", async () => {
  create
    .mockResolvedValueOnce(toolUse("get_order"))
    .mockResolvedValueOnce(text("It ships Friday."));

  const answer = await supportAgent(client);

  expect(create).toHaveBeenCalledTimes(2);
  expect(answer).toContainAll(["ships", "friday"]);
});

Why it changed

Tests tell you that it broke. Lithe tells you where.

1

Record. Name a mock, wrap a client with traced(), or note() a decision.

2

Save. --report keeps every result and trace, with the commit it came from.

3

Compare. See what broke, what got fixed, and what passes but behaves differently.

$ npx lithe compare main.json branch.json

In CI

One command, any pipeline.

GitHub Actions

Save a report on every build and compare pull requests against main.npx lithe --report lithe-report.json

Anywhere else

GitLab, CircleCI, Azure, Jenkins. Lithe exits non-zero when a test fails.npm ci && npx lithe

Real models

More time and a second try for tests that call a live API.npx lithe e2e --timeout 60000 --retries 2
