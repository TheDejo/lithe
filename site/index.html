Lithe is an open-source test runner for AI agents, like Jest. Write down what an agent should and shouldn't do, run it on every commit, and see exactly where its behaviour changed.

$ npm i -D @thedejo/lithe

What it does

  • Testsdescribe, test and expect, the way you already write them. TypeScript runs as is, with no config.
  • MocksStub the Anthropic or OpenAI client your agent already uses, script the model's replies, and check every tool call.
  • AssertionsCheck meaning, not wording. Match parts of a string, a shape of JSON, or one of several good answers.
  • RetriesGive real model calls more time and another try, and still see which tests needed it.
  • TracesEvery model call, tool call and note is recorded. When a test fails, you see the steps that led there.
  • CompareDiff two runs and find the first step where an agent did something different, even when its tests still pass.

How it looks

Write it down

Stub the client, script what the model says, and assert on what the agent does with it.

const create = spyOn(client.messages, "create");

test("looks up the order first", async () => {
  create
    .mockResolvedValueOnce(toolUse("get_order"))
    .mockResolvedValueOnce(text("It ships Friday."));

  const answer = await supportAgent(client, "Where's A-1042?");

  expect(create).toHaveBeenCalledTimes(2);
  expect(answer).toContainAll(["ships", "friday"]);
});

Run it

Lithe finds your test files and exits non-zero when one fails, so CI stops the change.

$ npx lithe

tests/support.test.ts
  ✓ looks up the order first
  ✓ answers directly when no lookup is needed
  ✓ surfaces a refusal instead of an empty answer

Tests: 3 passed (3)

Know why it changed.

Save a record of every run with --report. Compare two of them, and Lithe points to the first step where the agent went another way.

$ npx lithe compare main.json branch.json

✗ now failing  plans a day of sightseeing (pass → fail)
   first difference at step 1:
   - note: query "things to do in Chicago"
   + note: query "Chicago restaurants"

~ behaviour changed  keeps the city in the plan

Run it in CI

Works anywhere Node 20 runs · Guides

  • GitHubSave a report on every build, keep it as an artifact, and compare pull requests against main.npx lithe --report lithe-report.json
  • Anywhere elseGitLab, CircleCI, Azure, Jenkins or Buildkite. Lithe exits non-zero when a test fails.npm ci && npx lithe
  • Real modelsGive the slower tests that call a live API more time, and a second try.npx lithe e2e --timeout 60000 --retries 2
